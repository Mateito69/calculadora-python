# Calculadora en Python (Tkinter)

Calculadora básica con interfaz gráfica moderna (tema oscuro) creada en Python usando `tkinter`.

## Características
- Operaciones básicas: suma (`+`), resta (`-`), multiplicación (`×`), división (`÷`), porcentaje (`%`) y cambio de signo (`±`).
- Evaluación matemática segura mediante `ast`.
- Soporte completo de teclado numérico y atajos (`Enter`, `BackSpace`, `Escape`).

## Ejecución

```bash
python calculadora.py
```
